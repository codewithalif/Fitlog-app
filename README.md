# FitLog 🏋️‍♂️

FitLog is a web application designed to help users browse exercises, create a daily workout plan, and easily track their fitness activities.

🔗 **Live Site:** [https://fitlog-app01.netlify.app/](https://fitlog-app01.netlify.app/)

---

## 🌟 Features

* **Exercise Library** — Browse workouts with details like equipment needed, target muscle groups, duration, and instructions.
* **Today's Plan** — Add exercises to your daily plan, mark tasks as complete, or remove them when done.
* **Saved Plan** — Save your favorite exercises for later and manage them easily.
* **Workout Tracker / Summary** — View total exercises, total minutes, and estimated calories burned in real time.
* **Filter & Search** — Filter workouts by muscle group or category to quickly find the right exercise.
* **Fully Responsive** — Works smoothly on mobile phones, tablets, and desktop devices.

---

## 🛠️ Tech Stack

* **Framework:** Next.js / React
* **Language:** JavaScript / TypeScript
* **Styling:** Tailwind CSS
* **Deployment:** Netlify
